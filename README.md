
# Campus Route Navigator

An AI Mini Project that finds walking routes between college buildings using graph algorithms.

## Project Objective
Build a digital representation of a college campus where:
- Buildings are represented as graph nodes.
- Walking paths are represented as weighted edges.
- Edge weights represent walking distances.
- Users select a starting point and destination.
- A* finds an optimal route.
- BFS and DFS are used for comparison.
- Explored nodes and routes are visualized.

## Technology Stack
- Java
- Java Swing
- Graph Data Structures
- A*, BFS and DFS
- Git and GitHub
- Maven
